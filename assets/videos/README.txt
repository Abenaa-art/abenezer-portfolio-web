PUT YOUR VIDEO FILES IN THIS FOLDER
-----------------------------------
Example:  assets/videos/my-promo.mp4

Then write the same path in js/config.js:  video: "assets/videos/my-promo.mp4"

Tips:
- Use .mp4 (H.264 video + AAC audio). It plays on every phone and browser.
- Keep each file under about 25 MB (see the README.md guide to shrink them).
- File names: lowercase, no spaces, e.g. my-promo.mp4
